Rulebook: docs/rules/TKID2_rulebook.pdf (git-ignored, never commit). `pdftoppm` is installed for
rendering pages. pdftotext extraction of p6, p7 and p9 matched the rendered pages (checked 2026-10-30);
p9 card text has bold/italic emphasis only, no extra rules hidden in art.

Page map: p2 overview/contents, p4 setup, p6 turns/power struggles/taking actions/summon/partial
actions, p7 game end, p8 four-player, p9 base action cards, p10-11 cunning actions (advanced only).
